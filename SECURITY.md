# Security Policy

## Supported Project

CyberGate is an educational and defensive AI-security project.

Security issues affecting the current version of CyberGate are welcome.

## Reporting a Vulnerability

If you discover a security vulnerability in CyberGate, please report it privately to the project maintainer rather than publicly disclosing sensitive details.

Please include:

- A short description of the issue
- The affected component or file
- Steps to reproduce the issue in an authorized environment
- The potential security impact
- Any suggested remediation

Please do not include API keys, AWS credentials, passwords, tokens, or other secrets in a report.

## Responsible Disclosure

Please allow reasonable time for the issue to be reviewed and addressed before publicly disclosing technical details.

## Security Scope

CyberGate is intended for defensive, educational, and authorized use only.

Do not use the project to access systems, accounts, or data without permission.
